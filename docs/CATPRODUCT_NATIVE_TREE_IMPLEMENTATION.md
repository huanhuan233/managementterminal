# CATProduct Native Tree Implementation

## Current Data Sources

- CAA native bundle JSONL: `product_instances.jsonl`, `product_references.jsonl`, `native_features.jsonl`, `native_feature_topology_links.jsonl`, `native_mesh_face_map.jsonl`, `native_mesh_triangles.jsonl`, `native_topology_*.jsonl`, `business_features.jsonl`, and `parameters.jsonl`.
- Preferred JSONL now emitted by CAA writer and generated by backend fallback when older bundles are ingested: `native_tree_nodes.jsonl` and `node_properties.jsonl`.
- Backend publication path: Component Build viewer manifest exposes native assets under `native-caa/...`.
- Frontend consumer: `frontend/src/views/feature-center/index.vue` with `NativeFeatureTree.vue` and selection modules.

## Current Gaps

- Existing frontend builds a CATPart-style feature tree directly from `native_features.jsonl`; CATProduct BOM identity and repeated instances are not represented in the same tree.
- Existing native feature records do not always identify the owning CATPart reference. When a CATProduct has multiple references and no explicit mapping, the backend must not attach all features to all instances.
- CATIA-like basic property tabs are represented by `node_properties.jsonl`; advanced mass/graphic/material property enrichers still require R21 public-interface validation.
- Geometry may be unavailable even when BOM, features, and properties are usable.

## This Change Set

- Add a backend native tree adapter that builds a unified tree from preferred JSONL when present, otherwise falls back to current native bundle files.
- Preserve instance and reference identity; repeated instances get distinct node IDs such as `instance:I001/feature:F010`.
- Add derived `native_tree_nodes.jsonl`, `node_properties.jsonl`, and `native_tree_diagnostics.jsonl` publication when a native CAA bundle is present.
- Extend feature-center frontend types and tree projection so UI logic uses explicit fields rather than labels.
- Add CAA C++ contract records, writer output, manifest/capability metadata, and API-independent writer coverage for `native_tree_nodes.jsonl` and `node_properties.jsonl`.
- Add x64-host helper scripts without changing the existing x86 R21 build path.

## Locally Verifiable

- Python adapter tests for Chinese JSONL, source ordering, duplicate product instances, same-reference multi-instance IDs, no-geometry bundles, missing optional JSONL, unknown nodes, property grouping, empty properties, and invalid JSONL diagnostics.
- Frontend TypeScript tests for CATProduct BOM rendering, repeated instances, cloned feature IDs, selection detail data, property dialog data, and dynamic property tabs.
- API-independent C++ tests via `3DjiexiCAA/tools/test_core_vs2008.bat`.
- Real x86 R21 chain on this machine: `tools/build_r21_x86.bat` and `tools/run_r21_x86.bat --self-test`.

## Requires Full CAA R21 Prerequisite Validation

- CATPart traversal through `CATIPrtContainer`, `CATISpecObject`, and `CATIContainer`.
- CATProduct recursion through `CATIProduct` and ProductStructure APIs, including reference document access.
- Advanced property enrichers that read mass, graphic, color-management, or material tabs beyond already verified basic identity/product data.
- `CATINavigateObject` remains unimplemented unless public header evidence is found in the installed framework.
